Beyond Skate's North Perth store is built around an indoor park rather than the other way round, which changes what a shop visit can be: try transition in a bowl, ask about the setup that would suit it, and book a clinic if you want coaching. The park's headline features are two linked bowls, a brick wallride and an over-vert taco with pool coping — an intermediate-and-up park, so treat the lessons as the entry point if you are early in a comeback. Open seven days; hours vary by day, so check the store page.
